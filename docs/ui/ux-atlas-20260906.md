The adversarial review found two state bugs: defining FacetRail inside RepositoryBrowser caused React to remount the disclosure on every keystroke; an older search response could replace newer input after the newer debounce fired. Rendering the rail as stable JSX preserves the disclosure, and tracking the requested query prevents stale input replacement. Enter submits search immediately. Category hrefs now preserve the same filters as ordinary clicks, including modified clicks and no-JavaScript navigation. A persistent status area indicates pending results without a layout jump.
