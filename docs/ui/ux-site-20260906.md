## Implementation

- Replaced the animated homepage with a split hero and a Bell circuit whose Qiskit code matches the Studio parser fixture. The diagram labels the H, controlled-X and measurement operations; it makes no execution or verification claim.
- The prompt is a single input with an editable example. It carries the draft into Nala without starting a run. Removed the attachment/plan controls that only opened the account dialog.
- Added five direct destinations: Nala, Studio, Atlas, Notebooks and Qapps. The walkthrough uses the existing product video with native controls and `preload="none"`; it does not autoplay.
- Added a responsive public navigation disclosure with outside-click and Escape recovery, active-page state, locale and theme controls, and client navigation. RootDocument must import `apps/web/styles/ux-site.css` after the base CSS during lead integration.
- Workspace and Free-plan CTAs open `/run`. Paid-plan links carry a validated plan name to an editable contact message.
- Contact submission now closes rapid duplicate requests with a synchronous guard, protects fields while sending, aborts after 20 seconds, retains the draft after failure, and exposes a reusable mailto fallback. Copy distinguishes prepared email from server delivery.
- Removed decorative motion from About, retained all founder names, roles, affiliations and biography facts, and made profiles horizontal at desktop widths. Removed the repeated workflow section.
- Demo view selection resolves on the server; navigation uses links with current-page state and copy describes sample data. Auth error chrome no longer performs a server auth lookup, preserves the safe return path, and provides retry/contact recovery. Legal pages have contents links; policy text is unchanged.
- Both benchmark copy objects are byte-identical to the baseline, including numbers, sources and comparison limitations. Prices, cadence and feature lists remain unchanged.
