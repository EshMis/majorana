# Workspace navigation UX — 2026-09-06

Part of the owner-authorized full UX revamp. Durable cross-lane plan and browser evidence: `/Users/Eshaan/Developer/ai-ops/desk/leona/plans/ux-revamp-20260906/`.

## Changes

- Vertical, full-width navigation for Run, Studio, Qapps and Notebooks, with a direct Atlas link.
- Search across local chat and circuit titles, including items in folders. Dedicated notebook and course navigation.
- Workspace route links use client navigation. New-work actions retain their reset semantics.
- Sidebar hydration starts independent reads together. Local history events refresh local state without refetching every remote list.
- Phone navigation starts closed before hydration, traps focus while open, supports Escape and backdrop dismissal, makes the background inert, and closes after navigation. Desktop collapse preference is independent of phone use and reflected before hydration.
- Skip link, visible focus, larger navigation targets and a hidden closed account drawer.
- Content stays visible during scrolling; Reveal no longer hides or replays content. Loading placeholders stay still and fit the viewport.
- Error messages offer a retry without unsupported claims about saved data or automatic incident reporting. Segment boundaries no longer nest main landmarks.
